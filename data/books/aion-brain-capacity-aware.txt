1. ARCHITECTURE OVERVIEW
================================================================================

OLD FLOW (Current):
-------------------
User Message → Brain Router → [OpenAI → A2E → Anthropic → Echo] → Answer

NEW FLOW (Capacity-Aware Dispatch):
-----------------------------------
User Message → Brain Router
              ↓
         [CLASSIFY] — Local heuristic scoring (0ms, zero API cost)
              ↓
         [DISPATCH] — Pick rewrite + answer models based on profile
              ↓
         [REWRITE CHAIN] — Optimize prompt using cheapest qualified model
              ↓
         [ANSWER CHAIN] — Generate final answer using best-fit frontier model
              ↓
         SSE Stream → Frontend

KEY PRINCIPLE:
--------------
"Right tool for the sub-task." The system reads the prompt like a project 
manager estimating scope, then assigns the cheapest qualified model that can 
actually complete that specific job without failing.

================================================================================
2. PROMPT CLASSIFICATION ENGINE
================================================================================

PURPOSE:
--------
Before any external API call, Brain scores the prompt locally using regex,
heuristics, and token patterns. Zero latency, zero cost.

FOUR CLASSIFICATION AXES:
-------------------------

Axis 1: COMPLEXITY (1-10)
  Measures: Multi-step reasoning, dependencies, domain jargon, nested logic.
  Heuristics:
    - Counts transition words: "first, then, finally, additionally, moreover"
    - Detects nested conditionals: "if X then Y else if Z then W"
    - Domain keyword density: legal, medical, financial, cryptographic terms
    - Question depth: "explain" (low) vs "derive, prove, architect" (high)

  Scoring:
    1-2: Greeting, single fact, casual chat
    3-4: Simple question, one-step task
    5-6: Multi-step analysis, comparison, basic code
    7-8: Architectural reasoning, complex debugging, multi-file analysis
    9-10: Formal proofs, novel algorithm design, cross-domain synthesis

Axis 2: CONTEXT LOAD (0-10)
  Measures: How much background knowledge is assumed or attached.
  Heuristics:
    - Message token count (approximate)
    - Presence of URLs, file paths, repo names, commit hashes
    - Attached document indicators: "see below", "attached", "refer to"
    - Conversation history length (if multi-turn)

  Scoring:
    0-1: No external context, self-contained question
    2-4: One URL or short code snippet
    5-7: Multiple files, repo analysis, medium document
    8-9: Large codebase, 50+ page document
    10: 100K+ token document, entire codebase analysis

Axis 3: OUTPUT RIGOR (0-10)
  Measures: Structured output demands, precision requirements.
  Heuristics:
    - "return as JSON", "output table", "markdown list", "CSV"
    - Type hints requested: "typed", "interface", "schema"
    - Test cases requested: "unit tests", "edge cases", "100% coverage"
    - Citation demands: "cite sources", "with references", "numbered"

  Scoring:
    0-2: Free-form text, conversational
    3-5: Bullet points, basic structure
    6-7: JSON, tables, formatted code blocks
    8-9: Strict schemas, typed interfaces, validation rules
    10: Formal specification, mathematical notation, proof format

Axis 4: SAFETY SENSITIVITY (0-10)
  Measures: Legal, medical, financial, or security implications.
  Heuristics:
    - Regex for liability terms: "advice", "recommend", "should I", "is it safe"
    - Medical patterns: "diagnosis", "treatment", "prescription", "symptoms"
    - Financial patterns: "invest", "portfolio", "tax", "legal entity"
    - Security patterns: "exploit", "vulnerability", "bypass", "hack"
    - PII detection: emails, SSNs, credit cards, API keys in prompt

  Scoring:
    0-2: General knowledge, creative, neutral
    3-5: Technical guidance, coding help
    6-7: Business strategy, general health info
    8-9: Financial advice, legal interpretation, security audit
    10: Medical diagnosis, legal representation, critical infrastructure

CLASSIFICATION FUNCTION:
------------------------
```javascript
// lib/classify.js
function classifyPrompt(messages, history = []) {
  const lastUserMsg = messages.filter(m => m.role === 'user').pop()?.content || '';
  const text = lastUserMsg.toLowerCase();
  const tokenEstimate = Math.ceil(lastUserMsg.length / 4); // Rough approximation

  // --- COMPLEXITY ---
  let complexity = 1;
  const stepWords = ['first', 'then', 'next', 'finally', 'step', 'phase', 'stage'];
  const deepWords = ['derive', 'prove', 'architect', 'synthesize', 'optimize', 'analyze deeply'];
  const nestedIndicators = text.match(/if.*?then.*?else/g) || [];

  complexity += stepWords.filter(w => text.includes(w)).length * 0.5;
  complexity += deepWords.filter(w => text.includes(w)).length * 1.5;
  complexity += nestedIndicators.length * 1.0;
  complexity += (tokenEstimate > 500) ? 1 : 0;
  complexity += (tokenEstimate > 2000) ? 1 : 0;
  complexity = Math.min(10, Math.max(1, complexity));

  // --- CONTEXT LOAD ---
  let contextLoad = 0;
  const urls = text.match(/https?:\/\/[^\s]+/g) || [];
  const filePaths = text.match(/[\w-]+\/[\w-]+\/[^\s]+|\w+\.\w{2,4}/g) || [];
  const repoPatterns = text.match(/github\.com\/[\w-]+\/[\w-]+/g) || [];

  contextLoad += urls.length * 0.5;
  contextLoad += filePaths.length * 0.3;
  contextLoad += repoPatterns.length * 1.0;
  contextLoad += (tokenEstimate > 1000) ? 1 : 0;
  contextLoad += (tokenEstimate > 10000) ? 2 : 0;
  contextLoad += (tokenEstimate > 50000) ? 3 : 0;
  contextLoad += (history.length > 10) ? 1 : 0;
  contextLoad = Math.min(10, Math.max(0, contextLoad));

  // --- OUTPUT RIGOR ---
  let outputRigor = 0;
  const structureWords = ['json', 'table', 'csv', 'schema', 'interface', 'type', 'format'];
  const testWords = ['unit test', 'edge case', 'coverage', 'assert', 'test suite'];
  const citeWords = ['cite', 'reference', 'source', 'numbered', 'annotated'];

  outputRigor += structureWords.filter(w => text.includes(w)).length * 1.0;
  outputRigor += testWords.filter(w => text.includes(w)).length * 1.0;
  outputRigor += citeWords.filter(w => text.includes(w)).length * 0.5;
  outputRigor += text.includes('```') ? 1 : 0; // Code block requested
  outputRigor = Math.min(10, Math.max(0, outputRigor));

  // --- SAFETY SENSITIVITY ---
  let safety = 0;
  const medicalTerms = ['diagnosis', 'treatment', 'prescription', 'symptom', 'disease', 'medical'];
  const financialTerms = ['invest', 'portfolio', 'tax', 'stock', 'option', 'derivative', 'legal entity'];
  const securityTerms = ['exploit', 'vulnerability', 'bypass', 'hack', 'penetration', 'cve'];
  const adviceTerms = ['should i', 'recommend', 'advice', 'is it safe', 'what do you think about'];
  const piiPattern = /\d{3}-\d{2}-\d{4}|[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}/;

  safety += medicalTerms.filter(w => text.includes(w)).length * 1.5;
  safety += financialTerms.filter(w => text.includes(w)).length * 1.0;
  safety += securityTerms.filter(w => text.includes(w)).length * 1.0;
  safety += adviceTerms.filter(w => text.includes(w)).length * 0.5;
  safety += piiPattern.test(lastUserMsg) ? 2 : 0;
  safety = Math.min(10, Math.max(0, safety));

  return {
    complexity,
    contextLoad,
    outputRigor,
    safety,
    estimatedTokens: tokenEstimate,
    rawText: lastUserMsg
  };
}
```

// ============================================================================
// DISPATCH ENGINE
// ============================================================================

function dispatch(messages, history = [], userPreferences = {}, headers = {}) {
  // Step 1: Classify the prompt
  const profile = classifyPrompt(messages, history);

  // Step 2: Check user override headers
  const forceRewrite = headers['x-optimize-prompt'] === 'true';
  const forceNoRewrite = headers['x-optimize-prompt'] === 'false';
  const preferredAnswer = headers['x-prefer-model']; // e.g., "kimi", "grok"

  // Step 3: Filter viable models by context window
  const viableModels = Object.entries(MODEL_REGISTRY)
    .filter(([_, spec]) => spec.maxContext >= profile.estimatedTokens * 2); // 2x safety margin

  // Step 4: Decide if rewrite is needed
  let rewriteModel = null;

  if (!forceNoRewrite && (forceRewrite || profile.complexity > 3 || profile.outputRigor > 4)) {
    // Score each viable model for rewrite suitability
    const rewriteCandidates = viableModels
      .filter(([name, spec]) => {
        // Only NVIDIA models + Kimi for rewrite (cheap/fast tier)
        return spec.provider === 'nvidia' || (spec.provider === 'kimi' && profile.contextLoad > 8);
      })
      .map(([name, spec]) => ({
        name,
        spec,
        score: calculateRewriteScore(spec, profile),
      }))
      .sort((a, b) => b.score - a.score);

    if (rewriteCandidates.length > 0) {
      rewriteModel = rewriteCandidates[0];
    }
  }

  // Step 5: Select answer model
  let answerCandidates = viableModels
    .map(([name, spec]) => ({
      name,
      spec,
      score: calculateAnswerScore(spec, profile, preferredAnswer),
    }))
    .sort((a, b) => b.score - a.score);

  // If user prefers a specific provider, boost it
  if (preferredAnswer) {
    answerCandidates = answerCandidates.sort((a, b) => {
      const aMatch = a.spec.provider === preferredAnswer ? 100 : 0;
      const bMatch = b.spec.provider === preferredAnswer ? 100 : 0;
      return (b.score + bMatch) - (a.score + aMatch);
    });
  }

  const answerModel = answerCandidates[0];

  // Step 6: Build reasoning log
  const reasoning = [
    `Profile: complexity=${profile.complexity}/10, context=${profile.contextLoad}/10,`,
    `rigor=${profile.outputRigor}/10, safety=${profile.safety}/10,`,
    `estimatedTokens=${profile.estimatedTokens}`,
    `Rewrite: ${rewriteModel ? rewriteModel.name : 'NONE (passthrough)'}`,
    `Answer: ${answerModel.name}`,
    `Rationale: ${buildRationale(rewriteModel, answerModel, profile)}`,
  ].join(' ');

  return {
    profile,
    rewrite: rewriteModel ? {
      modelKey: rewriteModel.name,
      provider: rewriteModel.spec.provider,
      model: rewriteModel.spec.model,
      maxTokens: 1024,
      temperature: 0.2,
      timeout: 5000,
    } : null,
    answer: {
      modelKey: answerModel.name,
      provider: answerModel.spec.provider,
      model: answerModel.spec.model,
      maxTokens: estimateAnswerTokens(profile),
      temperature: 0.7,
      timeout: 60000,
    },
    reasoning,
  };
}

// ============================================================================
// SCORING FUNCTIONS
// ============================================================================

function calculateRewriteScore(spec, profile) {
  let score = spec.rewriteScore * 10; // Base capability

  // Context window penalty
  if (profile.estimatedTokens > spec.maxContext * 0.5) {
    score -= 50;
  }

  // Speed bonus for simple rewrites
  if (profile.complexity <= 5) {
    score += (10 - spec.latencyMs / 200); // Faster = better for simple stuff
  }

  // Reasoning bonus for complex rewrites
  if (profile.complexity >= 7) {
    score += spec.strength === 'reasoning' ? 20 : 0;
    score += spec.strength === 'long-context' ? 15 : 0;
  }

  // Cost efficiency bonus
  score += (6 - spec.costTier) * 3; // Cheaper is better for rewrite

  return score;
}

function calculateAnswerScore(spec, profile, preferredAnswer) {
  let score = spec.answerScore * 10; // Base capability

  // Context window is king for long docs
  if (profile.contextLoad >= 8) {
    score += spec.maxContext > 500000 ? 30 : 0;
    score += spec.strength === 'long-context' ? 25 : 0;
  }

  // Safety sensitivity
  if (profile.safety >= 7) {
    score += spec.strength === 'safety' ? 30 : 0;
    score += spec.provider === 'anthropic' ? 15 : 0;
  }

  // Output rigor demands structured output
  if (profile.outputRigor >= 8) {
    score += spec.provider === 'openai' ? 10 : 0; // GPT-4o best at structured
  }

  // Direct execution preference
  if (profile.complexity >= 6 && profile.outputRigor >= 7) {
    score += spec.strength === 'execution' ? 15 : 0;
  }

  // Cost penalty for simple tasks
  if (profile.complexity <= 4 && profile.outputRigor <= 4) {
    score -= (spec.costTier - 2) * 5;
  }

  return score;
}

function buildRationale(rewrite, answer, profile) {
  const parts = [];

  if (!rewrite) {
    parts.push('Prompt is simple; skipping rewrite to minimize latency.');
  } else if (rewrite.spec.strength === 'long-context') {
    parts.push(`Using ${rewrite.name} for rewrite because only it can handle ${profile.estimatedTokens} tokens.`);
  } else {
    parts.push(`Using ${rewrite.name} for rewrite (cost tier ${rewrite.spec.costTier}, ${rewrite.spec.latencyMs}ms).`);
  }

  if (answer.spec.strength === 'long-context') {
    parts.push(`Using ${answer.name} for answer due to massive context requirement.`);
  } else if (answer.spec.strength === 'safety') {
    parts.push(`Using ${answer.name} for answer due to high safety sensitivity.`);
  } else if (answer.spec.strength === 'execution') {
    parts.push(`Using ${answer.name} for answer due to direct execution requirement.`);
  } else {
    parts.push(`Using ${answer.name} for answer (strength: ${answer.spec.strength}).`);
  }

  return parts.join(' ');
}

function estimateAnswerTokens(profile) {
  // Heuristic: complex prompts need longer answers
  const base = 512;
  const complexityBonus = profile.complexity * 128;
  const rigorBonus = profile.outputRigor * 64;
  return Math.min(4096, base + complexityBonus + rigorBonus);
}

// lib/rewrite.js
// Prompt Optimization Layer for Aion-Brain

const SYSTEM_PROMPT_FOR_REWRITING = `
You are an elite Prompt Engineer. Rewrite the user's raw prompt into a 
highly effective, structured version that maximizes LLM comprehension and 
output quality.

Apply these optimization principles:
1. ROLE ANCHORING — Start with: "You are a [senior/expert] [role]..."
2. CONTEXT INJECTION — Add implicit background needed for correct reasoning.
3. TASK DECOMPOSITION — Break complex requests into numbered steps.
4. OUTPUT SCHEMA — Mandate exact format: JSON, markdown, tables, code blocks.
5. CONSTRAINTS & GUARDRAILS — Define scope, length, tone, exclusions.
6. FEW-SHOT FRAMING — Include brief example of desired output when helpful.
7. REASONING VERIFICATION — Add self-check: "Before finalizing, verify..."
8. AMBIGUITY ELIMINATION — Replace vague terms with precise actions.

Rules:
- Preserve original intent EXACTLY. Do not add new requirements.
- Return ONLY the rewritten prompt. No explanations, no markdown fences.
- The output must be immediately usable as a standalone user message.
`;

class PromptRewriter {
  constructor(providerChain) {
    this.providerChain = providerChain;
    this.circuitBreaker = new Map(); // Per-rewrite-provider circuit state
  }

  async rewrite(messages, dispatchPlan, callId) {
    if (!dispatchPlan.rewrite) {
      return { messages, rewritten: false, model: null, latencyMs: 0 };
    }

    const rewriteConfig = dispatchPlan.rewrite;
    const lastUserIndex = messages.findLastIndex(m => m.role === 'user');
    if (lastUserIndex === -1) {
      return { messages, rewritten: false, model: null, latencyMs: 0 };
    }

    const originalMessage = messages[lastUserIndex];
    const startTime = Date.now();

    try {
      // Check circuit breaker
      if (this.isCircuitOpen(rewriteConfig.modelKey)) {
        console.log(`[${callId}] Circuit open for ${rewriteConfig.modelKey}, skipping rewrite.`);
        return { messages, rewritten: false, model: null, latencyMs: 0, reason: 'circuit_open' };
      }

      // Call the rewrite model
      const response = await this.providerChain.call(rewriteConfig.provider, {
        model: rewriteConfig.model,
        messages: [
          { role: 'system', content: SYSTEM_PROMPT_FOR_REWRITING },
          { role: 'user', content: `Optimize this prompt for maximum LLM effectiveness:

${originalMessage.content}` }
        ],
        max_tokens: rewriteConfig.maxTokens,
        temperature: rewriteConfig.temperature,
        timeout: rewriteConfig.timeout,
      });

      const latencyMs = Date.now() - startTime;

      // Extract and clean the rewritten prompt
      let optimized = response.choices[0].message.content.trim();

      // Strip accidental markdown fences
      if (optimized.startsWith('```')) {
        const lines = optimized.split('
');
        if (lines[0].startsWith('```')) lines.shift();
        if (lines.length && lines[lines.length - 1].startsWith('```')) lines.pop();
        optimized = lines.join('
').trim();
      }

      // Record success for circuit breaker
      this.recordSuccess(rewriteConfig.modelKey);

      // Build new message array with optimized content
      const newMessages = [...messages];
      newMessages[lastUserIndex] = {
        ...originalMessage,
        content: optimized,
        _meta: {
          rewritten: true,
          original: originalMessage.content,
          rewriteModel: rewriteConfig.modelKey,
          rewriteLatencyMs: latencyMs,
          rewriteTokens: response.usage?.total_tokens || 0,
        }
      };

      return {
        messages: newMessages,
        rewritten: true,
        model: rewriteConfig.modelKey,
        latencyMs,
        tokensUsed: response.usage?.total_tokens || 0,
      };

    } catch (err) {
      const latencyMs = Date.now() - startTime;
      this.recordFailure(rewriteConfig.modelKey);

      console.error(`[${callId}] Rewrite failed for ${rewriteConfig.modelKey}: ${err.message}`);

      return {
        messages,
        rewritten: false,
        model: rewriteConfig.modelKey,
        latencyMs,
        error: err.message,
        reason: 'rewrite_failed',
      };
    }
  }

  // Circuit breaker logic
  isCircuitOpen(modelKey) {
    const state = this.circuitBreaker.get(modelKey);
    if (!state) return false;
    if (state.failures < 3) return false;
    const recoveryTime = 30000; // 30 seconds
    if (Date.now() - state.lastFailure > recoveryTime) {
      this.circuitBreaker.delete(modelKey);
      return false;
    }
    return true;
  }

  recordSuccess(modelKey) {
    this.circuitBreaker.delete(modelKey);
  }

  recordFailure(modelKey) {
    const state = this.circuitBreaker.get(modelKey) || { failures: 0, lastFailure: 0 };
    state.failures += 1;
    state.lastFailure = Date.now();
    this.circuitBreaker.set(modelKey, state);
  }
}

module.exports = { PromptRewriter };

const COST_RATES = {
  'nvidia-llama-8b': { input: 0.00001, output: 0.00002 },
  'nvidia-llama-70b': { input: 0.0001, output: 0.0002 },
  'nvidia-llama-405b': { input: 0.0005, output: 0.001 },

  'openai-gpt-4o': { input: 0.0025, output: 0.01 },
  'kimi-k2.6': { input: 0.002, output: 0.008 },
  'xai-grok-3': { input: 0.003, output: 0.015 },
  'anthropic-claude-sonnet': { input: 0.003, output: 0.015 },
};

function estimateCost(modelKey, tokens) {
  const rate = COST_RATES[modelKey];
  if (!rate) return 0;
  // Assume 2:1 output:input ratio for estimation
  const inputTokens = tokens * 0.33;
  const outputTokens = tokens * 0.67;
  return (inputTokens / 1000 * rate.input) + (outputTokens / 1000 * rate.output);
}

================================================================================

REWRITE CIRCUIT BREAKER:
------------------------
- Failure threshold: 3 consecutive failures
- Recovery time: 30 seconds
- Fallback behavior: Return raw prompt (passthrough)
- The answer chain proceeds normally regardless

ANSWER CIRCUIT BREAKER (existing):
----------------------------------
- OpenAI fails → try A2E → try Anthropic → Echo (mock)
- Unaffected by rewrite circuit state

CASCADING FAILURE SCENARIOS:
----------------------------

Scenario A: NVIDIA is down
  Rewrite: Circuit opens after 3 failures → passthrough
  Answer: Normal chain (OpenAI → A2E → Anthropic → Echo)
  User impact: Slightly less polished answers, zero downtime

Scenario B: OpenAI is down
  Rewrite: NVIDIA works normally
  Answer: Fails over to A2E or Anthropic
  User impact: Different answer quality, but prompt is still optimized

Scenario C: Both NVIDIA and OpenAI are down
  Rewrite: Circuit open → passthrough
  Answer: Fails over to Anthropic or Echo
  User impact: Raw prompt to backup provider. Still functional.

Scenario D: Kimi is chosen for rewrite (long context) but Kimi is down
  Rewrite: Falls back to Llama 405B (if context fits) or passthrough
  Answer: Falls back to GPT-4o (if context fits) or error
  User impact: If context > 128K and Kimi is down, system returns error:
  "This request requires a model with >128K context window, which is currently unavailable."

13. COST TRACKING & ROI MEASUREMENT
================================================================================

HOW SAVINGS ARE CALCULATED:
---------------------------

Baseline assumption: Without the optimizer, ALL prompts go directly to the 
answer model (usually GPT-4o or the most expensive suitable model).

With optimizer:
  Total cost = Rewrite cost + Answer cost

Savings = Baseline cost - Total cost

The SQLite log captures both, so you can query:

```sql
-- Daily savings report
SELECT 
  date,
  COUNT(*) as total_calls,
  SUM(CASE WHEN phase = 'rewrite' THEN cost_usd ELSE 0 END) as rewrite_cost,
  SUM(CASE WHEN phase = 'answer' THEN cost_usd ELSE 0 END) as answer_cost,
  SUM(estimated_baseline_cost_usd) as baseline_cost,
  SUM(estimated_baseline_cost_usd) - SUM(cost_usd) as savings_usd,
  ROUND((SUM(estimated_baseline_cost_usd) - SUM(cost_usd)) / SUM(estimated_baseline_cost_usd) * 100, 2) as savings_percent
FROM calls
LEFT JOIN cost_savings USING (date)
GROUP BY date
ORDER BY date DESC;
```

EXPECTED ROI:
-------------
- Simple prompts (30% of traffic): No rewrite → 0% overhead, 0% savings
- Standard prompts (50% of traffic): 70B rewrite + GPT-4o answer → ~25-40% savings
- Complex prompts (15% of traffic): 405B rewrite + frontier answer → ~15-30% savings
- Long-context (5% of traffic): Kimi rewrite + Kimi answer → Impossible without, so "infinite" savings vs failure

Overall expected savings: 20-35% on total LLM spend
